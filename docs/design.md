# StockPilot V0.1 界面设计文档

> 职责：定义“页面如何呈现”。产品范围见 `prd.md`。  
> 前端实现时优先参考 `ui-demo.html`，该文件作为 V0.1 的视觉与布局基线；允许根据真实数据和组件实现做合理调整，但不要无理由完全重做整体风格。

## 1. 设计定位

方向：

> **金融 Dashboard + AI Copilot + Developer Portfolio**

关键词：深色、简洁、技术感、信息密度适中、Agent 突出。

避免：完整复刻券商终端、过多指标、过度动画、独立套壳 Chat UI。

```text

│ Sidebar   │ Topbar：搜索 / 市场状态            │
│           ├──────────────────────┬─────────────┤
```

建议：
- Sidebar：约 220px
- Agent 列：380～430px
- 主内容：自适应
- Desktop First，重点 ≥1280px

Sidebar：
- 市场概览
- 自选股
- AI Agent
- Agent Eval（P1）

自选股入口指向 `/#watchlist`；选中状态同时识别路径和锚点，蓝点与 `aria-current` 只标记当前入口。点击、跨页跳转、刷新、浏览器前进/后退均保持一致。

## 4. Dashboard `/`

### 顶部
- `市场概览`
- 股票代码 / 名称搜索
- 交易状态、数据延迟

### 三大指数
上证、深证、创业板；展示点位、涨跌幅、涨跌额、成交额。

### 市场走势
默认上证分时，每 2 秒刷新曲线；展示当前、高低、成交额和 ECharts Line。

### 自选股
字段：

```text
股票 | 现价 | 涨跌幅 | 成交额 | 换手率
```

点击进入 `/stock/[code]`。

### 市场温度
上涨家数、下跌家数、涨停家数、两市成交额。

当前 P0 API 尚无全市场统计，页面保留真实数据占位；该模块待 P1 数据能力接入后完成。

### Agent
首页保持可见，提供输入框和快捷问题：

```text
今天市场怎么样？
分析我的自选股
分析东方财富
比较宁德时代和比亚迪
```

首页提供实际对话输入和快捷问题；下方展示最近 Tool Trace 的名称、成功/失败状态、耗时和结果摘要。

## 5. 个股详情 `/stock/[code]`

顺序：

```text
股票头部 → 基础行情 → K线/成交量 → 资金流 → 新闻 → AI快捷分析
```

股票头部示例：

```text
宁德时代 300750 · 深交所
251.30   +1.72%
```

支持加入 / 移出自选。

行情图：
- `分时 | 日 K | 周 K`，进入新个股默认分时。
- 分时使用最新交易日真实分钟价格折线 + 成交量柱图，显示数据最后时间，每 2 秒刷新；基础报价每 10 秒刷新。休市时显示最近交易日，不合成分钟点。
- 同一资源上次请求尚未完成时跳过该轮刷新，避免慢源请求堆积和旧响应覆盖新响应；切换股票或周期时取消旧请求。
- 日/周 K 使用 ECharts Candlestick + Volume，不复权、最近 120 根，每 60 秒刷新。
- 数据源失败时提供重试；有最近成功数据时继续显示并明确标注旧缓存。
- 成功行情持久化到 SQLite，页面刷新、切换回来或后端重启后，数据源失败时仍能加载有效旧快照。报价、指数、分时、日/周 K 与自选股报价显示“行情暂未更新，正在显示旧缓存”及北京时间缓存保存时间，并提供重试更新；分时仍显示数据最后时间，每 2 秒刷新。旧快照最多用于降级 7 天，未曾保存、过期或损坏的快照不展示。
- V0.1 不强制 MACD / KDJ / RSI

AI 快捷入口：

```text
分析今日表现
分析最近 5 日
总结相关新闻
```

资金流与新闻当前仅显示 P1 数据待接入；AI 快捷入口进入 `/agent` 并预填当前股票问题。

## 6. Agent 工作台 `/agent`

```text
┌───────────────────────────┬─────────────────────┐
│ Chat                      │ Execution Trace     │
│                           │ Tool Input / Output │
└───────────────────────────┴─────────────────────┘
```

Agent 回答优先使用简洁结构化信息。

当前工作台提供可滚动对话、快捷问题、新对话和模型未配置提示；刷新页面时按浏览器保存的会话 ID 从后端恢复可见消息。右侧展示当前会话的完整 Tool Trace，包括失败步骤；失败响应也会恢复对应会话供查看。

首页和工作台共用 Markdown 流式对话组件：用户消息立即显示，助手先显示读取行情状态，随后逐段追加最终回答；粗体、标题、列表、引用、代码和表格按 Markdown 渲染，不执行原始 HTML。回复过程中可停止；中断内容显示“未保存”，输入框保留原问题便于重试。默认跟随新内容滚动，用户向上查看历史时停止自动跟随。完整回答结束后持久化会话并刷新 Trace；浏览器恢复的历史回答也按 Markdown 渲染。

Trace：

```text
✓ get_watchlist       42ms
✓ get_stock_quote    287ms
! get_stock_kline    504ms
```

每条记录直接显示 Status、Latency 与 Output Summary，可展开查看 Input 和结果摘要。Trace 只展示实际执行的 Tool，不展示模型内部推理。

## 7. Agent Eval（P1）

只展示：

```text
Tool Selection Accuracy
Argument Accuracy
Task Success Rate
```

附少量失败 Case，定位为工程调试页。

## 8. 通用状态

- Loading：Skeleton
- Error：简洁错误 + 必要时重试
- Empty：给出下一步操作
- 数据源旧缓存：显示 `stale` 提示

窄屏时 Sidebar 收起，Agent 下移，表格允许横向滚动。

## 9. 设计原则

1. 数据可读性优先。
2. Agent 融入看盘流程，不做独立聊天套壳。
3. Trace 清晰可见但不抢主内容。
4. 无明确用途的模块不加入首页。
5. 以 `docs/ui-demo.html` 为 V0.1 视觉基线；明显偏离布局、信息层级或整体风格时，应先同步更新本文。
