# StockPilot

StockPilot 是面向 A 股的本地看盘与 AI 辅助分析应用，将指数、自选股、个股走势和 AI 对话放在同一个工作台。

## v0.1 功能

- **市场概览**：三大指数及分时走势。
- **自选股**：搜索添加、移除、批量报价、涨跌幅升降序排序。
- **个股详情**：报价、分时价格与成交量、日 K / 周 K。
- **自动更新**：报价、指数与分时每 2 秒查询；失败时保留有效旧行情并标注时间。
- **AI 分析**：通过工具读取行情，支持流式回答、Markdown、停止生成与历史对话。
- **执行追踪**：查看 AI 调用的工具、参数、结果摘要、状态与耗时。
- **本地保存**：SQLite 保存自选股、对话、执行记录和行情快照。

实时报价来自东方财富公开接口；最新主分支的个股及三大指数分时、历史日 K / 周 K 在东方财富失败时自动尝试腾讯财经备用接口，页面标注实际来源，历史 K 线均使用不复权数据。腾讯接口无需额外 API Key。AI 使用 OpenAI 兼容模型服务，需要自行提供模型 API Key；不配置模型也可以看行情。v0.1 暂不提供交易下单、资金流、新闻与全市场涨跌家数统计。

## 安装与运行

需要 Python **3.13+**、[uv](https://docs.astral.sh/uv/getting-started/installation/)、Node.js **20.9+** 和 npm。

### 1. 下载项目

```bash
git clone https://github.com/Tosidxyy/vibe_stock.git
cd vibe_stock
```

也可以从 [Releases](https://github.com/Tosidxyy/vibe_stock/releases) 下载源码并解压。当前发布为源码版本，需要分别启动前后端。

### 2. 配置后端

复制根目录 `.env.example` 为 `backend/.env`：

```powershell
# Windows PowerShell
Copy-Item .env.example backend/.env
```

```bash
# macOS / Linux
cp .env.example backend/.env
```

需要 AI 对话时，在 `backend/.env` 填写服务商提供的配置：

```dotenv
MODEL_NAME=你的模型名称
MODEL_API_KEY=你的模型密钥
MODEL_BASE_URL=你的OpenAI兼容API地址
```

`MODEL_NAME`、`MODEL_API_KEY` 留空则禁用 AI 对话。真实密钥只放在本地 `.env`，不要写入配置模板。

### 3. 启动后端

在第一个终端执行：

```bash
cd backend
uv sync --locked
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

首次启动自动创建 SQLite 数据库。保持终端运行；[健康检查](http://127.0.0.1:8000/health) 应返回 `{"status":"ok"}`，[API 文档](http://127.0.0.1:8000/docs) 可查看接口。

### 4. 启动前端

另开一个终端，从项目根目录执行：

```bash
cd frontend
npm ci
npm run dev
```

打开 **[http://localhost:3000](http://localhost:3000)**。停止时，在两个终端分别按 `Ctrl+C`。

如需使用构建后的前端，先执行 `npm run build`，再执行 `npm run start`。开发时可在后端启动命令末尾加 `--reload`。

## 如何使用

1. 首页点击指数切换分时走势。
2. 顶部搜索股票，点击结果打开个股详情。
3. 在自选股中添加股票，或在详情页点击“加入自选”。
4. 点击“涨跌幅”表头，依次切换降序、升序、添加顺序；行情更新保持排序，整页刷新恢复默认。
5. 详情页切换分时、日 K、周 K。
6. 最新主分支可在详情查看个股新闻、首页查看市场新闻，按日期或关键词筛选、加载下一页、打开原文。
7. 详情页的“公司公告”支持公告日期、类型与标题关键词筛选；展开缓存正文、查看原文或下载公开附件。正文不完整时显示原因。
8. 配置模型后，向 AI Agent 提问，例如“查看我的自选股”“用宁德时代最近五根日 K 概括走势”“总结 300750 近三天新闻”“查看 300750 最近公告”或“查看 300750 最近五个交易日资金流”；右侧查看工具执行记录。

最新主分支的详情“资金流向”卡显示最新可用统计日的五类净流入及净占比，点击“查看近期”展开最多 30 个交易日记录。注意统计日期、来源与旧缓存提示，缺失字段显示“暂无数据”。

首页“市场温度”显示沪深京上涨、下跌、平盘及各市场来源时间，每 30 秒查询；涨停/跌停单独展示东方财富对应股池数量及日期。可向 AI 提问“查看市场涨跌家数”，通过工具读取共享缓存。

每 2 秒查询不代表每轮都有新成交或数值变化，分时点按分钟记录。自选股页面每 2 秒读取后台缓存；非自选股日/周 K 每 60 秒查询。第三方接口可能延迟或断连；已有有效行情会继续显示为旧缓存，并标注保存时间，快照最多用于降级 7 天。没有有效缓存时显示预热或不可用状态与重试入口。分时不可用时可点击“查看历史日 K”；历史 K 线可独立获取，不依赖实时报价成功。腾讯备用历史接口不提供成交额，该字段返回空值，不估算补齐。AI 工具优先读取最新有效缓存，并向模型提供数据时间与旧数据状态。

分时主源失败或返回空数据后，自动切换腾讯；该股票或指数在 30 秒内直接使用备用源，随后重试东方财富，恢复成功则切回。分时仅展示 09:30–11:30、13:00–15:00 常规交易时段，不包含源头的盘后交易。腾讯累计成交量（手）和成交额（元）转换为逐分钟增量；缺失分钟导致无法还原的增量保留为空，页面明确提示，不估算补齐。两源均失败时继续展示有效旧快照及原保存时间；该备用能力不包含实时报价。

## 可选配置

### V0.2 开发中：自选股后台采集、新闻、公告、资金流与市场统计

最新主分支已支持：后端启动后自动预热自选股的报价、分时、最近 120 根日 K / 周 K，关闭页面后继续采集。新增自选股进入预热，移除后停止后续采集；非自选股保持进入详情或显式工具调用时请求。

北京时间工作日 09:15–11:30、13:00–15:05，报价与分时以 2 秒为刷新目标，日/周 K 每 60 秒；其他时段每 300 秒，启动与新增成员仍预热一次。此时段判断不含节假日交易日历。慢源或多只股票会受到并发限制，成功数据才写入缓存；上游持续失败且无历史快照时仍可能无数据。

默认启用；在 `backend/.env` 可设置 `WATCHLIST_PREFETCH_ENABLED=false` 关闭，`WATCHLIST_PREFETCH_WORKERS=4` 设置分时最大并发（1–16）。使用一个后端进程运行，多个 worker 会重复采集。此功能尚未包含在已发布的 v0.1.0 标签中。

后台采集开启时，自选股页面、详情和 AI 工具直接读取同一份快照，冷启动等待后台预热，避免打开页面时重复取数。列表展示每只股票的采集状态，详情分别展示报价、分时、日 K、周 K 的状态、最近成功保存时间及历史数据来源。部分失败时保留成功内容；“重试更新”请求后台重新采集，仍遵循失败退避。关闭后台采集后恢复按需请求。

目前已验证真实日/周 K 自动落盘与缓存读取不增加源请求。腾讯分时备用已通过 4 只股票、三大指数真实 API 和页面验证，4 只自选股未打开详情即可后台保存分时；模拟两源失败后保留原曲线与保存时间。本轮在收盘后验收，不能替代开市期间持续 2 秒刷新与长期稳定性验证；实时报价源可用性仍待确认。

最新主分支已接入东方财富个股新闻搜索与“证券要闻”市场栏目，并新增 `get_stock_news` / `get_market_news` 工具。新闻保存到 SQLite，同篇报道可关联多只股票，不同关键词对应的来源片段分别保留。自选股新闻在后端启动及新增时预热，每 5 分钟更新，独立最多两只并发；页面关闭后仍采集。非自选股及市场新闻按需获取并缓存 5 分钟，关闭后台采集后自选股也按需获取。

每次最多获取源头前 100 条，展示最近 30 天内已采集的新闻；本地最多保留 10,000 篇，成功采集时清理过期和超容量记录。日期筛选按北京时间计算，翻页与关键词筛选读取本地记录，不保证完整历史覆盖。失败时保留旧新闻及原采集时间；无成功记录时明确显示预热或不可用。点击“更新新闻”可请求更新，仍受失败退避保护。

新闻列表和 AI 工具提供标题、来源、发布时间、原文链接及**来源片段（非全文）**。新闻股票关联来自代码关键词搜索，不能当作公司公告或确定的涨跌原因。新闻全文与检索增强回答仍未实现；新闻 API、浏览器展示、分页过滤、重启缓存及断网恢复已验证，真实模型新闻评测未重新运行。

公司公告已接入东方财富公开公告列表与附件，保存公告 ID、标题、公告日期、平台披露时间、类型、明确关联的股票及原文/附件链接。自选股启动和新增时自动采集，每 10 分钟更新，无需打开详情；列表与正文分别入库，正文在后台最多两份并发提取，不阻塞行情和新闻。非自选股进入详情或明确工具查询后按需获取；页面列表每 10 秒读取本地缓存。

每次最多获取前 100 条，保留最近 90 天的已采集公告；元信息最多 10,000 条，正文保留最新 1,000 份。公开 PDF 使用 pypdf 提取首个附件文本，限制 10 MiB、150 页、30 万字符。扫描页不做 OCR，多附件、空白页或超出上限明确标为部分正文；失败保留标题与原文入口，有成功正文时保留并标为旧版本。网页文字仅作未确认完整的片段降级。表格排版可能改变，重要数据请核对原 PDF；“报告摘要”本身不等于完整报告。

公告列表每轮更新；正文接口每轮检查附件链接与网页文本指纹，未变化的成功 PDF 在 24 小时内复用，读取不会刷新原正文保存时间。更正标题、链接变化或正文指纹变化会重新提取，失败保留旧正文。`get_stock_announcements` 工具共用 Service 缓存，可按文档 ID 读取最多 8,000 字，并返回正文状态、截至时间和截断提示。本轮未进行真实模型公告问答评测。

公告模块后端全量 **129 passed**，前端 lint / Type Check / Build 通过。使用独立 SQLite 和真实源，在未打开详情前采集贵州茅台、宁德时代共 59 条公告，55 条附件文本已提取、4 条标为部分正文；真实 API、缓存重复读取、浏览器筛选/分页/正文展开通过。没有将部分正文算作完整报告读取，原行情稳定性验收仍待完成。

资金流已接入东方财富日序列：主力、超大单、大单、中单、小单净流入（元）及净占比（%），保留来源最近最多 30 个交易日，日期去重并按实际统计日显示。主力为来源的大单与超大单分类统计，不等于机构账户真实持仓或新增资金；净流入不能独自证明涨跌原因。可通过卡片的[东方财富原始数据页面](https://data.eastmoney.com/zjlx/300750.html)核对来源。未补造缺失字段、未保证完整历史，也不将最近统计日称为今天。

自选股资金流在启动/新增时独立两并发预热，工作日交易时段采集目标 60 秒，其他时段 300 秒（沿用无节假日历的时段判断）；页面每 10 秒读取同一份缓存。非自选股进入详情或显式 Tool 请求后按需获取，Service 缓存 60 秒。`get_stock_money_flow` Tool 优先读缓存，limit 为 1–30 个交易日条数；API 为 `GET /api/stocks/{code}/money-flow`。失败保留 SQLite 原快照和保存时间，快照最多降级 7 天；无缓存显示预热或不可用，更新按钮仍遵循缓存与失败退避，不保证立即得到新源数据。移除自选股后停止后续资金流采集，关闭后台采集则恢复按需获取。

资金流模块后端全量 **170 passed**（新增 17 项），前端 lint / Type Check / Build 通过。真实独立库未打开详情即缓存贵州茅台、宁德时代各 30 条；页面/Tool 重复读取不增加源请求，API、键盘历史展开、模拟断网旧缓存与新 Service 从 SQLite 恢复通过。600578、002414 的官方接口直接断连，返回无缓存不可用；后续恢复尝试也未取得新源数据，不将其算作在线恢复通过。本轮在收盘后验证，开市持续更新及长期源可用性仍待最终验收；真实模型资金流回答评测未运行。更新代码后重启前后端使用，无新增依赖。

市场涨跌概览已接入东方财富[大盘星图](https://quote.eastmoney.com/stockhotmap/)采用的三市场计数，范围为沪深京 A 股，不含 B 股、基金和新三板；沿用来源的上涨/下跌/平盘分类，三市场来源更新时间可能不同。仅当三市场字段齐全、同日且没有局部旧值时显示合计；缺失为“—”，不当作零，也不按指数成分股数量代替市场计数。涨停/跌停来自[官方股池](https://quote.eastmoney.com/ztb/)，按统计日读取，其覆盖未保证与三市场计数一致，不按固定涨跌幅阈值估算，也不能与上述家数相加。

`GET /api/market/breadth` 与 `get_market_breadth` Tool 共用 30 秒缓存和 SQLite 快照，Tool 优先读最近有效缓存。某市场或股池缺失时保留该项已有旧值和来源时间，并标注部分数据；新部分快照的保存时间与各项来源时间分开显示。整个请求失败时保留原快照和原保存时间，无缓存返回不可用；“重试更新”仍受 TTL 与失败退避限制。此模块按需读取，不改变个股分时 2 秒轮询。

本模块后端全量 **197 passed**（新增 27 项），前端 lint / Type Check / Build 通过。真实 Provider 曾取得三市场计数，独立股池请求也验证了数据；随后源连接超时/断连，无缓存 API 返回 503。页面、部分缺失、断网缓存和 SQLite 恢复使用本轮先前保存的真实响应回放验证，未把回放算作当前在线成功，完整在线稳定性及真实模型评测仍待验收。更新后重启前后端，无新依赖。

## 常见问题

- **无法连接 API**：确认后端仍在运行，健康检查正常，前后端端口与地址配置一致。
- **行情不更新**：查看交易时段、数据时间与旧缓存提示。接口失败后会退避重试，没有缓存时需等数据源恢复。
- **AI 不可用**：检查模型名称、密钥、API 地址；修改 `backend/.env` 后重启后端。
- **数据在哪里**：默认保存在 `backend/stockpilot.db`，包含自选股、对话与执行记录。备份或迁移前先停止后端。

## 技术与检查

前端：Next.js、TypeScript、Tailwind CSS、ECharts。后端：FastAPI、PydanticAI、SQLAlchemy、SQLite。

后端测试在 `backend/` 执行 `uv run pytest`；前端检查在 `frontend/` 执行 `npm run lint`、`npx tsc --noEmit`、`npm run build`。

配置模型后，可在 `backend/` 执行 `uv run python ../evals/run_eval.py` 运行评测。评测实际请求模型、使用固定测试行情，不代表在线行情源的可用率。
