# StockPilot

StockPilot 是面向 A 股的本地看盘与 AI 辅助分析应用，将指数、自选股、个股走势和 AI 对话放在同一个工作台。

## v0.1 功能

- **市场概览**：三大指数及分时走势。
- **自选股**：搜索添加、移除、批量报价、涨跌幅升降序排序。
- **个股详情**：报价、分时价格与成交量、日 K / 周 K。
- **自动更新**：报价、指数与分时每 2 秒查询；失败时保留有效旧行情并标注时间。
- **AI 分析**：通过工具读取行情，支持流式回答、Markdown、停止生成与历史对话。
- **执行追踪**：查看 AI 调用的工具、参数、结果摘要、状态与耗时。
- **本地保存**：SQLite 保存自选股、对话、执行记录和行情快照。

v0.1 实时报价来自东方财富。最新主分支的个股与三大指数报价按腾讯财经 → 新浪财经 → 东方财富批量降级；个股及三大指数分时按新浪财经 → 腾讯财经 → 东方财富降级；历史日 K / 周 K 优先东方财富、腾讯备用，均不复权。页面标注实际来源，报价带来源时间；失败保留旧缓存。免费公开接口无需行情 Key，但没有可验证的长期服务保证。AI 使用 OpenAI 兼容模型服务，需要自行提供模型 API Key；不配置模型也可以看行情。v0.1 暂不提供交易下单、资金流、新闻与全市场涨跌家数统计。

## 主分支新增：手动统计股民情绪

在个股详情的股吧卡点击 **“统计当前股民情绪”**，使用 **DeepSeek Flash** 将已有近24小时样本分成积极、消极、中立，并展示数量、占比饼图与原文样本。页面加载、刷新、后台采集和普通 AI 工具读取不会自动开启分类。

- 统计最多200条去重公开发帖标题/页面附带回复，标注样本范围、来源采集时间与模型统计时间。
- 每批最多40条、全局两并发；重复点击同股合并为一个任务，未变化文本复用SQLite分类记录，不重复付模型调用成本。
- 空样本不画假比例；模型未配置明确提示；失败保留上次完整统计，未分类/失败不会算作中立。新样本或编辑文本需要再次点击统计。
- 显示统计进度，可继续导航和看行情；桌面及手机均显示三类图例。保存最多8条实际统计时的原文预览，避免把旧分类标签套到已编辑的新文本。

分类复用现有 `MODEL_API_KEY`、`MODEL_BASE_URL`，模型默认 `SENTIMENT_MODEL_NAME=deepseek-flash`。分类采用[DeepSeek JSON Output](https://api-docs.deepseek.com/guides/json_mode/)并校验ID、覆盖和三类标签，不记录私有推理。分类记录按文本/股票/模型/提示版本缓存30天、最多10,000条；最多保存256股的最后成功统计。任务运行于默认单后端进程，重启后已有结果可读取，未完成任务需重新点击。

API：`GET /api/stocks/{code}/sentiment` 读取样本；`GET /api/stocks/{code}/sentiment/analysis` 仅读任务/结果；`POST /api/stocks/{code}/sentiment/analysis` 显式开启统计。原样本API的关键词字段保留兼容，但新页面和已配置的工具使用手动模型统计，不把旧规则计数当模型结果。

后端全量 **374 passed**，最后相关34项通过，前端lint/TypeScript/build通过。两轮真实Flash对36条人工标注固定测试语料均36/36、macro-F1=1.0，[最终评测报告](evals/results/2026-10-08-sentiment-final.json)保留文本/标签与运行哈希；不代表真实股民样本的总体准确率。浏览器使用明确标注的6条固定样本和真实模型，验证点击前零调用、点击一次产生一次模型请求、再次点击/刷新复用、三类饼图、失败保留、空样本禁用和390px无横向溢出。

按2026-10-08用户修订，数据源可用性专项暂缓，现有来源失败和有限评论覆盖列为已知限制；**V0.2发布重点为手动情绪分类/饼图及加载性能**。当前模型模块已实现，性能/可选Redis和最终发布验收继续执行，尚未发布V0.2。没有可用样本时模型也不能生成当前情绪分布。更新后重启后端、重新构建/启动前端，无需清数据库。

## 安装与运行

需要 Python **3.13+**、[uv](https://docs.astral.sh/uv/getting-started/installation/)、Node.js **20.9+** 和 npm。

### 1. 下载项目

```bash
git clone https://github.com/Tosidxyy/StockPilot.git
cd StockPilot
```

也可以从 [Releases](https://github.com/Tosidxyy/StockPilot/releases) 下载源码并解压。当前发布为源码版本，需要分别启动前后端。

### 2. 配置后端

复制根目录 `.env.example` 为 `backend/.env`：

```powershell
# Windows PowerShell
Copy-Item .env.example backend/.env
```

```bash
# macOS / Linux
cp .env.example backend/.env
```

需要 AI 对话时，在 `backend/.env` 填写服务商提供的配置：

```dotenv
MODEL_NAME=你的模型名称
MODEL_API_KEY=你的模型密钥
MODEL_BASE_URL=你的OpenAI兼容API地址
```

`MODEL_NAME`、`MODEL_API_KEY` 留空则禁用 AI 对话。真实密钥只放在本地 `.env`，不要写入配置模板。

### 3. 启动后端

在第一个终端执行：

```bash
cd backend
uv sync --locked
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

首次启动自动创建 SQLite 数据库。保持终端运行；[健康检查](http://127.0.0.1:8000/health) 应返回 `{"status":"ok"}`，[API 文档](http://127.0.0.1:8000/docs) 可查看接口。

### 4. 启动前端

另开一个终端，从项目根目录执行：

```bash
cd frontend
npm ci
npm run dev
```

打开 **[http://localhost:3000](http://localhost:3000)**。停止时，在两个终端分别按 `Ctrl+C`。

如需使用构建后的前端，先执行 `npm run build`，再执行 `npm run start`。开发时可在后端启动命令末尾加 `--reload`。

## 如何使用

1. 首页点击指数切换分时走势。
2. 顶部搜索股票，点击结果打开个股详情。
3. 在自选股中添加股票，或在详情页点击“加入自选”。
4. 点击“涨跌幅”表头，依次切换降序、升序、添加顺序；行情更新保持排序，整页刷新恢复默认。
5. 详情页切换分时、日 K、周 K。
6. 最新主分支可在详情查看个股新闻、首页查看市场新闻，按日期或关键词筛选、加载下一页、打开原文。
7. 详情页的“公司公告”支持公告日期、类型与标题关键词筛选；展开缓存正文、查看原文或下载公开附件。正文不完整时显示原因。
8. 配置模型后，向 AI Agent 提问，例如“我的自选股哪只值得优先关注？”“结合走势、资金流和新闻，分析宁德时代”或“总结自选股近三天的重要资讯”。点击回答中的短编号或“来源与数据时间”展开实际原文、日期和缓存说明。

新闻和公告的日期、关键词及公告类型一起在点击“筛选”后生效，也可按 Enter 提交；修改条件后从第一页显示。“清除筛选”恢复全部已采集记录。起始日期晚于结束日期时提示修正并保留当前结果。

新闻、公告、资金流、市场统计和股吧情绪统一显示读取中、空结果、读取失败、部分数据及旧缓存。读取失败时保留当前查询已有内容与原保存时间，可点击“重试读取”；首次读取没有缓存时仅显示错误。采集保存时间与新闻发布时间、公告日期、资金流统计日期及市场来源时间分别标注。手机宽度可通过顶部导航切换市场概览、自选股与 AI Agent；历史资金流表格可在卡片内横向滚动，正文、分页及引用支持键盘操作。

本次 UI 整合：后端 **289 项 pytest 通过**，前端 lint / Type Check / Build 通过。使用独立受控样本验收状态、筛选、分页、正文及 Markdown 引用，检查首页、个股和 Agent 窄屏布局；这些界面测试不代表真实行情连续刷新或模型评测已经通过。V0.2 完整在线验收与发布仍在推进。

最新主分支的详情“资金流向”卡显示最新可用统计日的五类净流入及净占比，点击“查看近期”展开最多 30 个交易日记录。注意统计日期、来源与旧缓存提示，缺失字段显示“暂无数据”。

首页“市场温度”显示沪深京上涨、下跌、平盘及各市场来源时间，每 30 秒查询；涨停/跌停单独展示东方财富对应股池数量及日期。可向 AI 提问“查看市场涨跌家数”，通过工具读取共享缓存。

最新主分支支持本地资料检索。例如向 AI 提问：“检索 300750 在 2026-09-11 关于股票期权注销完成的公告，只根据已缓存片段回答并引用证据。”回答附实际片段 ID、资料日期、原文链接与完整性/旧缓存说明。未采集或未命中时会明确说明。

每 2 秒查询不代表每轮都有新成交或数值变化，分时点按分钟记录。自选股页面每 2 秒读取后台缓存；非自选股日/周 K 每 60 秒查询。第三方接口可能延迟或断连；已有有效行情会继续显示为旧缓存，并标注原保存时间，行情快照最多用于降级 14 天。没有有效缓存时显示预热或不可用状态与重试入口。分时不可用时可点击“查看历史日 K”；历史 K 线可独立获取，不依赖实时报价成功。腾讯备用历史接口不提供成交额，该字段返回空值，不估算补齐。AI 工具优先读取最新有效缓存，并向模型提供数据时间与旧数据状态。

个股和三大指数分时按 **新浪财经 → 腾讯财经 → 东方财富** 请求；前一源失败、超时或空数据才访问后一源。每股票/指数/来源独立记录失败：新浪按 2、4、8、16、30 秒退避，其他源冷却 30 秒；成功后重置。整条分时取数链共用 2 秒时间预算，预算耗尽时停止后续请求；失败继续展示有效旧快照及原保存时间。此顺序依据当前运行环境的实测可用性，不代表免费接口有长期稳定保证。

页面与自选股后台在交易时段仍以 **2 秒**为刷新目标。新浪返回 1 分钟 K 线，使用源标注的分钟周期时间和收盘价，末根可能尚未完成、价格可随请求变化；不是逐笔成交记录。仅保留最新交易日常规交易时段，不拼接前一天的数据。成交量由股换成手（保留不足一手的小数），成交额为元，缺失为空。腾讯累计量额则按原逻辑转为分钟增量，缺分钟时不估算补齐。页面如实显示实际来源，旧的东方财富缓存不会改标成新浪。

2026-09-29 本次优先级调整后，后端全量 **241 passed**，前端 lint / Type Check / Build 通过；腾讯成功不请求东方财富、失败回退、冷却恢复、个股/指数隔离和旧缓存保持已验证。本次真实腾讯请求返回 HTTP 501 防护页面，尚未验证当前在线连续 2 秒更新；此前成功的真实源验收仍作为历史记录，不代表本次可用性。2 秒是请求目标，分钟点和价格是否变化取决于源头；源受限或请求超时时仍可能显示旧缓存。更新后重启后端加载新优先级，前端生产运行需重新构建。

## 常见问题

- **无法连接 API**：确认后端仍在运行，健康检查正常，前后端端口与地址配置一致。
- **行情不更新**：查看交易时段、数据时间与旧缓存提示。接口失败后会退避重试，没有缓存时需等数据源恢复。
- **AI 不可用**：检查模型名称、密钥、API 地址；修改 `backend/.env` 后重启后端。
- **数据在哪里**：默认保存在 `backend/stockpilot.db`，包含自选股、对话与执行记录。备份或迁移前先停止后端。
